Практическая работа на тему подсчет слонов в заповеднике.
Веб-приложение для автоматического подсчета слонов на изображениях с использованием нейросетевой модел YOLOv8

Функциональные возможности:
•	загрузку изображений через веб-интерфейс; 
•	автоматическую передачу изображения на сервер;
•	 обработку изображения с использованием нейронной сети YOLOv8;
•	 обнаружение объектов, относящихся к классу «слон»;
•	 отображение изображения с нанесёнными ограничивающими рамками;
•	 подсчёт количества обнаруженных особей;
•	 отображение времени обработки изображения;
•	 сохранение истории выполненных операций учёта;
•	 экспорт истории обработки и результатов подсчёта в формат Microsoft Excel.

Стек технологий:
1.	Python 3.10+;
2.	Flask 2.3;	
3.	YOLOv8n (Ultralytics;
4.	OpenCV 4.8;
5.	JSON-файлы;
6.	openpyxl, pandas;
7.	HTML5, CSS3, JavaScript.


Результаты тестирования.
Тестирование разработанной системы проводилось на наборе из 6 изображений, содержащих от 0 до 4 особей слонов в различных условиях: на открытой местности, в лесной зоне, при разном освещении и ракурсах съёмки.
Точность детектирования. Модель YOLOv8n продемонстрировала среднюю точность обнаружения слонов на уровне 91,4%. Также была выбрана картинка где нет слонов для проверки корректности работы приложения. 
Производительность. Среднее время обработки одного изображения составило 0,068 секунды на компьютере без специализированного графического ускорителя. Это позволяет обрабатывать до 14 изображений в секунду, что значительно превышает потребности заповедника при анализе данных фотоловушек.
Надёжность. За время тестирования не было зафиксировано случаев падения сервера или потери данных. История обработок корректно сохранялась и восстанавливалась после перезапуска приложения. Все данные представлены в истории обработки и в таблице отчета.
